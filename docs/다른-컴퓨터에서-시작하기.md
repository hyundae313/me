# 다른 컴퓨터에서 시작하기

배포는 저장소를 기준으로 돌아가므로, 어느 컴퓨터에서 푸시하든 똑같이 반영됩니다.
새 컴퓨터에서는 아래 준비만 한 번 해두면 됩니다.

## 1. 필요한 것

- **Node.js 22 이상** — <https://nodejs.org> (LTS 버전)
  ```bash
  node -v      # v22 이상인지 확인
  ```
- **Git** — macOS 는 보통 이미 있습니다. 없으면 `xcode-select --install`

## 2. 저장소 받기

```bash
git clone https://github.com/hyundae313/me.git
cd me
npm install
```

`npm install` 은 처음 한 번만 하면 됩니다. `node_modules/` 폴더는 저장소에 없고
이 명령으로 새로 만들어집니다.

## 3. 실행해보기

```bash
npm run dev
```

<http://localhost:5173> 가 열리면 준비 완료입니다.

## 4. 푸시 인증 설정

여기가 유일하게 번거로운 부분입니다. GitHub 은 비밀번호 방식을 더 이상 받지 않아서
토큰이나 SSH 키가 필요합니다.

### 방법 A — 토큰 (간단하지만 만료됨)

1. <https://github.com/settings/personal-access-tokens/new>
2. **Repository access** → `Only select repositories` → `hyundae313/me`
3. **Permissions → Repository permissions** 를 펼쳐서 (기본값이 전부 `No access` 이므로
   여기를 반드시 직접 바꿔야 합니다):
   - `Contents` → **Read and write** ← 없으면 푸시 자체가 안 됩니다
   - `Workflows` → **Read and write** ← 배포 설정 파일을 고칠 때 필요
   - `Pages` → **Read and write**
4. Generate token 후 값 복사
5. 처음 `git push` 할 때 사용자명은 `hyundae313`, 비밀번호 자리에 토큰을 붙여넣습니다.

> 권한을 빼먹으면 `Permission to hyundae313/me.git denied` 가 뜹니다.
> 이때는 토큰을 다시 만들어야 합니다.

### 방법 B — SSH 키 (한 번 해두면 만료 없음)

```bash
ssh-keygen -t ed25519 -C "hyundae313@gmail.com"     # 계속 엔터
cat ~/.ssh/id_ed25519.pub                            # 출력된 내용 복사
```

복사한 공개키를 <https://github.com/settings/keys> 에서 **New SSH key** 로 등록한 뒤:

```bash
git remote set-url origin git@github.com:hyundae313/me.git
ssh -T git@github.com     # 인사말이 나오면 성공
```

## 5. 저장소에 없는 것들

`.gitignore` 때문에 아래는 따라오지 않습니다. 대부분 신경 쓸 필요 없습니다.

| 항목 | 설명 |
|---|---|
| `node_modules/` | `npm install` 로 생김 |
| `dist/` | 빌드 결과. 배포는 서버가 알아서 함 |
| `logs/` | 방문 로그. 수집기를 돌릴 때만 생김 |
| `.env` | 방문 추적 주소. 필요하면 `.env.example` 을 보고 새로 만들면 됨 |

[수정하고-배포하기.md](수정하고-배포하기.md) 와 똑같습니다.

```bash
npm run dev
git add -A && git commit -m "메모" && git push
```
